# Personal management

Use fictional records in tracked examples. Keep actual inputs in the approved
personal session or artifact.

### finance-review

Use for a financial audit, monthly or annual budget, or expense and subscription analysis. Work or Cowork with spreadsheet tooling · high effort for audits, standard for recurring budgets.

```text
Using [PERSONAL_RECORDS_OR_APPROVED_COPY] for [PERIOD_AND_CURRENCY], perform [AUDIT_BUDGET_EXPENSE_OR_SUBSCRIPTION_REVIEW]. Apply [CATEGORY_RULES_AND_GOALS]. Reconcile balances and totals to the supplied records, flag missing coverage and distinguish transfers, refunds and duplicates from spending.

Deliver period totals, recurring costs or variances, traceable calculations and decisions for review. Label estimates and avoid extrapolating from incomplete months without saying so. Keep accounts and payments read-only.
```

### fitness-nutrition-review

Use for workout logs, progress assessment, nutrition data or meal planning. Chat for a small log, Work or Cowork for a tracker · standard effort.

```text
Review [LOG_OR_FOOD_DATA] over [PERIOD] for [WORKOUT_PROGRESS_OR_MEAL_PLAN] using [GOALS_CONSTRAINTS_AND_UNITS]. Check coverage and inconsistent entries. For training, summarize trends using comparable sessions; for meals, use specified dietary restrictions and calculate portions from [NUTRITION_SOURCE_AND_MEASUREMENT_BASIS].

Return evidence-backed trends or a meal table with portions, totals and substitutions. Flag missing measurements and high-impact uncertainty. Keep changes to the tracker limited to [APPROVED_COPY_OR_RANGES].
```

### travel-cost-review

Use for car trips, fuel, FASTag tolls or commute comparisons. Work or Cowork with spreadsheets, Chat for a small comparison · standard effort.

```text
Analyze [TRIP_FUEL_AND_TOLL_RECORDS] for [PERIOD_OR_ROUTE]. Use [UNITS_CURRENCY_AND_COMPARISON_CRITERIA]. Reconcile fuel and toll charges to trips where evidence permits; flag ambiguous matches.

Return cost per trip and per distance with formulas, and compare [COMMUTE_OPTIONS] on time, cost and variability if provided. Date any route or price lookup. Output traceable totals, assumptions and a practical option for review.
```

### annual-planning

Use for an annual plan or a digital organization reset. Chat for discussion, Work or Cowork for multiple sources · standard effort.

```text
Create a [YEAR_OR_HORIZON] plan from [GOALS_OPEN_COMMITMENTS_AND_APPROVED_INVENTORY] within [TIME_AND_BUDGET]. Prioritize decisions, accountable next actions and review dates. For digital organization, include a proposed destination and ownership check for each move, archive or deletion.

Deliver a short plan with milestones and a first-week checklist. Flag incompatible goals, missing inputs and consequential actions for approval. Keep accounts, files and schedules unchanged.
```
